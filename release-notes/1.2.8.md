# TopNV 1.2.8

## Known issue on white and very light wallpapers

TopNV still does not work reliably on white or very light wallpapers. When the black band expands from the notch, parts of the menu bar can briefly turn gray when leaving Mission Control or Show Desktop. This remains unresolved in 1.2.8.

## Fixes and improvements

- Improved return timing after Mission Control and Show Desktop across macOS versions, including systems where the Dock manages Mission Control and displays with wider Show Desktop window edges.
- Mission Control exits are detected more reliably when macOS hides the band immediately on entry.
- When Reduce Motion is enabled in macOS, TopNV no longer allocates the extra animation windows.
- Removed per-frame diagnostic logging during return animations.
- Closing TopNV now tears down all overlay windows cleanly, and closing the first-launch automatic update prompt directly dismisses it cleanly.

Requires macOS 14 or later.

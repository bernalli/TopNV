# TopNV 1.2.0

- TopNV follows the system language: English, Italian, Spanish, French, German, Portuguese (Brazil), Japanese and Simplified Chinese.
- Simpler menu: Report an Issue… sits in the main menu, Options has Automatic Updates, and About matches MonoPods, with a Buy Me a Coffee button.
- New compact update window, in the style of a system alert.
- Corners use a fixed 15-point radius; the Corner Radius option is gone.
- Signed with Developer ID and notarized by Apple, so macOS opens TopNV without extra confirmation.

If you have TopNV 1.1.0, choose Check for Updates… to install 1.2.0.
If Launch at Login is off after the update, turn it on again in Options.

Requires macOS 14 or later.

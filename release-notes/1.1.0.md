# TopNV 1.1.0

- New name, TopNV, and a new app icon.
- Native menu with Options, icon visibility controls and an About window with version, source link and sponsor button.
- Screen corners no longer show in Mission Control.
- Check for updates manually from the menu, even with automatic checks off.
- Automatic checks start off. A one-time question offers to enable them; the choice remains available in Options.
- Install using Sparkle's standard two-step flow: Install Update, then Install and Relaunch. Updates never install silently.
- Scheduled updates use a temporary Dock icon and badge without taking focus. The icon disappears after attention or when the update session ends.
- Update DMG archives are verified with Ed25519 before extraction. The feed and its release notes are not signed.
- TopNV is now distributed under the MIT License, with the complete Sparkle notices included.

Upgrading from 1.0.0 requires downloading the DMG and manually replacing TopNV in Applications once, because 1.0.0 does not contain an updater.

Requires macOS 14 or later. The app uses an ad hoc signature and is not notarized. On first launch, if macOS blocks it, use System Settings > Privacy & Security > Open Anyway.
